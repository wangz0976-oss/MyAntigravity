## 安装和登录
首次安装默认使用 %LOCALAPPDATA%\MyAntigravity。需要另选盘符或文件夹时，在安装向导的“选择目标位置”页编辑路径，或按 Tab 到“浏览”。覆盖升级会沿用原安装目录，并保留程序同级的 data。

在“选择附加任务”页，用方向键在桌面快捷方式、开始菜单快捷方式和安装 Google 官方 CLI 之间移动，按空格勾选。CLI 安装默认未勾选，覆盖升级时也需要重新勾选。如果勾选，安装程序会检查已有 CLI，在需要时联网安装，并在进度页显示状态。CLI 安装失败会提示原因，MyAntigravity 可以照常完成安装。

启动时若未找到 agy.exe，会显示安装提示。按 Alt+A 运行 Google 官方安装命令，完成后自动检测版本。按 Esc 可稍后处理。也可以按 Alt+P 复制命令，按 Win+R 输入 powershell 并回车，粘贴命令后按回车执行。

在“账户 → 检测 CLI 版本”可以再次检测。自定义 CLI 路径可在“设置 → 常规设置”选择。

用“账户 → 用浏览器登录 Google”完成授权。已有 CLI 登录可以复用。按 Ctrl+Shift+S 查账户与连接，Alt+R 核验，Alt+U 刷新官方额度，Alt+D 复制连接诊断。额度是否可查由当前官方 CLI 提供的能力决定。

## 项目和会话
按 Alt 进入菜单，左右选择分类，下键打开，上下选择功能，按回车执行。F6 和 Shift+F6 在项目、历史、消息列表、输入框与状态区之间循环。

按 Ctrl+O 添加项目。按 Ctrl+Shift+O 可以快速打开已添加项目。项目列表按 Delete 只移除本机条目，可以重新添加原目录。

按 Ctrl+N 新建会话。历史列表按回车恢复会话，F2 重命名，Shift+F10 打开置顶、归档和删除本机记录的菜单。归档与本机删除由 MyAntigravity 管理，官方历史仍保留。从“会话 → 跨项目查找会话”可按项目、标题、日期或 ID 筛选各项目的本机历史，按回车直接打开。归档记录有“已归档”标记。

## 发送与阅读消息
默认 Ctrl+Enter 发送，Enter 换行，可在“设置 → 常规设置”交换。生成期间可按 Ctrl+Shift+Enter 追加指令，由当前官方 CLI 能力决定是否可用。

消息列表用上下键浏览，左右跳到上下一个用户提问，回车读全文，Esc 返回原位置。Ctrl+C 复制所选消息，Ctrl+F 查找会话消息。全文窗口按 Alt+B 定位代码块、Alt+Y 复制代码块、Alt+L 查看链接。Ctrl+Shift+R 可朗读最近回复。

未发送的文字和最后选中的历史消息位置会按会话保存。打开同一会话后，输入框会恢复草稿，官方 CLI 回放历史时会尽量回到原阅读位置。需要导出时，选“消息 → 导出文本 → 当前会话”或“所选消息”。先核对预览，再按 Alt+S 保存为 UTF-8 文本。

## 附件、审批和中止
按 Ctrl+Shift+I 管理图片，按 Ctrl+Shift+J 管理文本与代码附件。附件窗口按 Ctrl+O 添加，回车预览，Delete 从草稿移除。图片单张最多 8 MiB，合计 12 MiB。文本支持 UTF-8 与带 BOM 的 UTF-16，单个最多 256 KiB，合计 1 MiB。附件随草稿保留在本次运行期间。

Ctrl+M 查看模型、权限模式与推理等级。官方 CLI 发来审批时，焦点先落在详情。方向键阅读，Tab 到按钮。Alt+Y 允许本次，回车或 Esc 拒绝。需要逐段看审批附带的差异时按 Alt+W。Ctrl+Shift+X 中止当前任务。

## 任务结果和文件差异
“任务 → 本轮结果”列出当前任务的工具输出、文字、链接和关联文件。用方向键选结果，按回车读详情，有结构化差异时按 Alt+W 审查。Esc 返回此前选中的结果。发送下一轮消息时会换成新一轮的结果。

在结果列表按 Alt+F 切换“只看失败工具”。失败项详情按 Alt+E 可复制这一项的错误。若工具报告了文件位置，按 Alt+J 可在应用内打开只读预览并定位行号，按一次 Esc 回到结果列表原位置。支持当前项目和附加工作目录中最多 1 MiB 的 UTF-8 或带 BOM 的 UTF-16 文本。若工具返回了支持的内嵌图片，按 Alt+I 查看图片和文件格式、大小与尺寸。
在只读文件预览中，按 Ctrl+F 输入关键词并回车，按 F3 找下一处。按 Ctrl+G 输入行号并回车可直接跳转。

“任务 → 任务活动”可回看当前运行期间的执行、失败与审批记录。Ctrl+L 查看任务日志，Ctrl+Shift+L 查看任务计划。Ctrl+D 打开文件差异，Ctrl+Page Up 或 Page Down 切换文件，F7 和 F8 切换差异段。

## Git 工作树和规则
“项目 → 查看 Git 项目改动”可逐项审查已暂存、未暂存、未跟踪和冲突文件。“项目 → Git 工作树”可以打开现有工作树，或从当前 HEAD 创建新分支与工作树。

要清理工作树，在工作树列表选中附属目录后按 Delete 或“检查并移除”。有锁定、未提交改动、未跟踪文件或忽略文件时，窗口会给出阻止移除的原因。干净的工作树经确认后由 Git 移除，已提交内容、分支与本机会话记录保留。

Ctrl+Shift+W 管理项目附加工作目录。Ctrl+F9 打开规则、技能、MCP 与插件入口。“规则”可以浏览标准位置的规则文件，用方向键选择后回车阅读。

## 更新
“设置 → 检查更新”可手动检查，也可在常规设置中开启或关闭启动时检查。发现新版时，弹窗会将焦点放在将要安装的版本日志上。用方向键阅读，Tab 到“更新”后用空格或回车下载，窗口显示进度。Esc 可关闭提醒或取消下载。

“帮助 → 查看更新日志”可回看当前安装版本的改动和对应菜单入口。

如果更新窗口报告 GitHub 暂时限制访问，按 Alt+O 打开发布页。下载安装包，沿用原安装目录即可覆盖升级。
