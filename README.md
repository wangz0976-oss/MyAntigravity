# MyAntigravity

面向盲人及低视力开发者的 Windows 客户端。它调用 Google Antigravity CLI 的 ACP 接口，让你用标准 Windows 控件和键盘选择项目、读写会话、审批工具操作和检查文件修改。MyAntigravity 是免费、开源的独立项目，与 Google 和 OpenAI 无官方隶属关系。感谢地理课代表分享 MyCodex 的读屏交互经验与使用手册。来源见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 在 Windows 上开始

**先记一个键就能找功能。** 按 **Alt** 进入主菜单，用左右方向键选“项目”“会话”“消息”“任务”“账户”“设置”或“帮助”。按下方向键打开，上下选择，回车执行，**Esc** 返回。

“帮助 → 查看说明”可离线按章节阅读操作手册。“帮助 → 查看更新日志”可回看当前安装版本的改动、菜单和按键。

1. 打开 `dist\app\MyAntigravity.exe`。也可以运行 `dist\MyAntigravity-Setup.exe`。首次默认安装到 `%LOCALAPPDATA%\MyAntigravity`，简体中文安装向导可另选路径。“选择附加任务”页可用方向键和空格选择桌面快捷方式、开始菜单快捷方式或安装官方 CLI。当前产物是 Windows x64 版，自带 .NET 运行时。
2. 启动时缺少 CLI 会打开提示窗口。按 **Alt+A** 可以运行 Google 官方 PowerShell 安装命令，完成后自动检测版本。也可以按 **Alt+P** 复制命令手动执行。需要再次检测时，选择“账户 → 检测 CLI 版本”。自定义位置可在“设置 → 常规设置”选取 `agy.exe`。安装命令和默认路径也见 [Google 官方 Windows CLI 安装指南](https://antigravity.google/docs/getting-started?tab=cli)。
3. 使用“账户 → 用浏览器登录 Google”，在 Google 页面完成授权后返回。已有官方 CLI 登录状态会自动复用，可以直接新建会话。需要终端授权时选“用官方终端登录”，它运行官方命令 `agy acp --login`。
4. 按 **Ctrl+O**，输入完整项目路径并按回车。也可以在对话框选“浏览文件夹”。按 **Ctrl+N** 新建会话。输入消息，用 **Ctrl+Enter** 发送。回车换行。**Ctrl+M** 打开当前会话的模型、权限模式和推理等级。权限模式有中文说明，模型名沿用官方原名。用方向键选配置项，按 Tab 到可选值，再按一次 Tab 查看说明。
5. 用 **F6** 与 **Shift+F6** 切换项目、历史、消息列表、输入、状态区。消息列表用上下选择、左右跳到上一轮或下一轮提问，按 **回车** 阅读全文、**Esc** 返回。列表里的 **Ctrl+C** 复制当前消息全文，**Ctrl+F** 在当前会话查找消息，也可从“消息”菜单进入这些操作。“任务”菜单可查看日志、文件差异和状态，也可中止任务。若 CLI 无响应，选择“断开并停止 ACP”，随后从历史恢复。
6. 在“消息”菜单选择“朗读所选消息”，或按 **Ctrl+Shift+R** 朗读最新回复。在默认目录安装争渡时，程序会调用争渡语音接口。手动朗读时，接口不可用会打开正文供阅读。全文窗口中，**Alt+B** 跳到代码块，**Alt+Y** 复制当前或选中的代码块，**Alt+L** 查看和定位网页链接。
7. 审批弹窗先把焦点放在详情。可用方向键阅读，或按 **Ctrl+Shift+R** 让争渡朗读详情。用 **Alt+Y** 允许本次，也可按 Tab 找到“允许本次”按钮后按空格。回车或 Esc 拒绝，**Ctrl+Shift+X** 中止任务。何时出现审批由官方 CLI 的权限配置及会话模式决定。
8. 按 **Ctrl+Shift+O** 搜索已添加的项目，或按 **Ctrl+K** 按名称、日期或 ID 查找当前项目的会话。会话列表中按 **F2** 可保存本地名称，清空后恢复默认显示。官方自动生成的标题只在当前运行期间显示。
9. 打开会话后按 **Ctrl+Shift+P** 搜索该会话收到的官方命令。方向键选命令，Tab 可读说明及参数，回车填入输入框。内容核对后按 **Ctrl+Enter** 发送。
10. 在历史会话列表按 **Shift+F10** 打开会话操作菜单，可恢复、重命名或移入本地归档。按 **Ctrl+Shift+A** 归档历史列表中选中的会话，按 **Ctrl+Shift+H** 查找本地归档并恢复。归档不会删除官方会话。
11. 在支持图片的会话按 **Ctrl+Shift+I** 打开图片附件。按 **Ctrl+O** 选图，列表用方向键选择，回车查看图片及文件名、尺寸、格式和大小，**Delete** 从草稿移除，**Esc** 返回。支持 PNG、JPEG、GIF、BMP 和 TIFF，最多 8 张，单张 8 MiB、合计 12 MiB。附件随消息发送，原文件路径不会放入 ACP 请求。图片待发送项保留在本次运行的内存中。
12. 按 **Ctrl+Shift+S** 打开“账户与连接”。这里显示上次登录核验时间、官方返回的套餐（如有）、当前 ACP 连接及 CLI 版本。按 **Alt+R** 重新核验。核验会打开独立的空会话，不发送消息。使用官方 CLI 1.5.0 或更新版本时，按 **Alt+U** 刷新模型额度，窗口会显示官方返回的剩余比例和重置时间。按 **Alt+T** 也可打开官方终端并复制 `/usage`，在终端按 **Ctrl+V**、**回车**查询。**Ctrl+I** 还可以查看官方 ACP 报告的会话上下文与最近一轮 token 用量。
13. 按 **Ctrl+D** 打开文件差异审查。用 **Ctrl+Page Up / Down** 切换文件，**F7 / F8** 切换差异段，也可用方向键选择、回车进入差异段或阅读详情。审批包含差异时，可以按 **Alt+W** 打开同一个审查窗口，返回后再作决定。
14. 在“任务 → 任务计划”查看 ACP 提供的计划与进度，也可以按 **Ctrl+Shift+L**。“设置 → 技能、MCP 与插件”可以打开官方插件列表。
15. 在“项目列表”“历史会话”或“本地归档”按 **Delete** 打开移除确认。主窗口也可用列表的 **Shift+F10** 菜单。移除项目条目会保留磁盘目录和会话，重新添加目录即可看到原历史。删除会话只清理 MyAntigravity 的本机记录和这条会话的草稿，官方会话仍保留。在快选窗口直接用方向键浏览，按 **Ctrl+F** 可选填筛选词。
16. 在支持嵌入内容的会话中按 **Ctrl+Shift+J** 打开文本与代码附件。按 **Ctrl+O** 选文件，回车阅读文本，**Delete** 从草稿移除。支持 UTF-8 和带 BOM 的 UTF-16，每条最多 8 个文件，单个最多 256 KiB，合计最多 1 MiB。按 **Ctrl+Enter** 发送后，官方 Agent 收到文件名和文本快照。快照随本次运行的会话草稿保存在内存。
17. 官方 Agent 发来提问表单时，用 **Tab** 依次听问题和字段，用方向键、空格或输入框填写。核对后按 **Alt+S** 提交，按 **Alt+D** 拒绝回答，按 **Esc** 取消这一表单，或按 **Ctrl+Shift+X** 中止当前任务。
18. 按 **Ctrl+Shift+W** 管理当前项目的附加工作目录。按 **Ctrl+O** 添加目录，**Delete** 从清单移除，**Alt+S** 保存。支持此能力的官方 CLI 在新建或恢复会话时将这些目录加入工作范围。项目列表的 **Shift+F10** 菜单还可以复制路径或在文件资源管理器打开项目。
19. 使用已验证的 Antigravity CLI 1.5.13 或更新版本时，在任务生成过程中输入补充文字，按 **Ctrl+Shift+Enter** 追加到当前任务。表单和审批处理完后可继续追加。服务器拒收时，补充文字会回到对应会话的草稿。
20. 按 **Ctrl+F9** 打开规则、技能、MCP 服务和插件入口。“规则”列出标准位置的项目、附加目录和全局规则。用方向键选，按回车读正文，Esc 返回原位置。技能窗口按回车阅读说明，当前会话提供技能命令时按 **Alt+I** 填入消息框。MCP 服务窗口显示全局和工作目录配置，用 **Alt+R** 刷新，用 **Alt+T** 确认后启用或停用所选全局配置。重新打开会话后应用。

**查看任务过程。** 打开“任务 → 任务活动”，用上下键浏览执行、失败和等待审批的记录，按回车进入详情，Shift+Tab 返回列表。活动更新时会保留当前选择。

**浏览本轮结果。** 从“任务 → 本轮结果”查看当前任务已收到的工具输出、结果文本、链接和关联文件。用方向键选择，回车查看详情，有结构化差异时按 **Alt+W** 逐段审查。Esc 返回选中的工具。开启下一轮后显示新一轮的结果。
在结果列表按 **Alt+F** 可只看失败工具，失败项详情按 **Alt+E** 复制这条错误。报告了文件位置时按 **Alt+J** 在应用内只读预览当前项目或附加目录里的文本并定位行号，按一次 Esc 回到结果列表原位置。官方 ACP 返回支持的内嵌图片时按 **Alt+I** 查看。
只读文件预览中，按 **Ctrl+F** 输入关键词并回车，按 **F3** 找下一处。按 **Ctrl+G** 输入行号并回车，可直接跳转。

**查看整个 Git 工作区。** 先打开项目，再选“项目 → 查看 Git 项目改动”。选择已暂存、未暂存、未跟踪或有冲突的条目，回车打开差异审查。可用 F7 和 F8 切换文本差异段。需要系统安装 Git，此入口只读取改动。

**在单独的 Git 工作树开发。** 从“项目 → Git 工作树”查看分支、目录和提交，也可以打开现有工作树作为项目。新建时输入完整目录路径和新分支名，程序会从当前 HEAD 创建工作树并打开它。

**检查并移除工作树。** 在 Git 工作树列表选中附属工作树，按 Delete 或“检查并移除”。程序会检查锁定、当前占用、未提交改动和 Git 忽略的文件。确认后再检查一次，由 Git 移除干净的工作树目录，分支和本机会话历史保留。

**置顶常用会话。** 在历史会话中选中本地记录，再打开“会话”菜单或按 **Shift+F10**，可以置顶或取消置顶。已置顶的记录排在历史顶部。会话归档后暂时离开历史列表，恢复归档后保留置顶。

**跨项目查找会话。** 从“会话 → 跨项目查找会话”查阅所有已添加项目的本地记录，按项目、标题、日期或会话 ID 筛选。归档会话带有标记，打开后保留归档状态。

**导出已载入的对话。** 从“消息 → 导出文本”选择当前会话或所选消息。预览后用 **Alt+S** 选择保存位置，得到 UTF-8 文本，内容与预览一致。

**调整输入和朗读。** 打开“设置 → 常规设置”，可把发送键改成 Enter，此时 Ctrl+Enter 用来换行。可单独开启“自动朗读已完成的新回复”，使用已安装的争渡接口朗读新回复。

**接着写、接着读。** 已打开会话的未发送文字和最后选中的消息位置会保存到本机 `data\settings.json`。重新打开同一会话时，输入框恢复草稿。CLI 回放历史时，消息列表会定位到上次选中的附近。图片和文本附件仍在本次运行期间保留。删除本机会话记录时一起清理草稿和阅读位置。

**分享连接诊断。** 在“账户与连接”按 **Alt+D** 可复制应用版本、CLI 版本、登录核验和连接状态。诊断省略完整路径、账号和消息内容。装好 CLI 后可直接按 **Alt+R** 重新检测并核验。

历史列表默认显示本程序为当前目录记录的会话。选中会话后按回车或 Ctrl+H 恢复，需要时可在“会话 → 查看官方历史”查看已存在的官方会话。CLI 1.5.12 在测试中会把部分旧会话标为当前目录，恢复前请确认对应项目。会话消息历史由 Google CLI 保管，日志与差异在客户端内存中供本次运行查看。

在源码主目录内运行或安装时，程序使用主目录下的 `data`。独立分发时使用程序旁的 `data`。Google 账户缓存由官方 CLI 按它自己的规则管理。

## 从源码构建

需要 Windows、.NET 10 SDK 和 Git。项目里已有 `local\dotnet\dotnet.exe` 时，可以用它运行下面的 `dotnet` 命令。打包使用 Inno Setup 6.7.4。CI 也使用同一套发布脚本。

```powershell
dotnet build MyAntigravity.sln -c Release
dotnet run --project tests/MyAntigravity.Tests -c Release --no-build
pwsh -NoProfile -File packaging/Build-Release.ps1 -Iscc 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

自动测试使用隔离的 ACP 子进程和 HTTP 夹具。另可运行真实集成测试，使用已有 Google 登录状态，在项目内的空目录创建一个官方测试会话并发送一条连通消息。

```powershell
dotnet run --project tests/MyAntigravity.Tests -c Release --no-build -- --live .\local\agy\agy.exe
```

## 更新与分发

程序启动后会按设置中的渠道检查 GitHub Releases。发现新版时，焦点先落在纯文本更新日志，可以用方向键逐行读。按 Tab 到“更新”，按空格或回车开始下载，窗口会显示进度条和百分比。按 Esc 可关闭提醒或取消下载。可以在设置里关闭“启动时检查更新”，也可以随时从菜单手动检查。

GitHub 访问受限时，更新窗口会指出失败步骤。按 **Alt+O** 打开公开发布页，下载安装包后沿用原目录覆盖。发版时将改动和操作入口写到 [更新日志](CHANGELOG.md) 的相应版本节，发布脚本默认从该节生成更新清单。

发布脚本从 `Directory.Build.props` 读取版本，构建当前 `dist`，包括便携运行目录、Inno Setup 安装包和更新清单。应用校验 SHA-256 后才打开安装程序。覆盖安装默认沿用已有安装目录，保留同级 `data`、设置与会话索引。安装程序临时保留已安装的可执行文件，升级成功后清理，安装失败时尝试恢复。恢复遇到文件锁时，关掉应用后重新运行安装包即可继续。

获准发布时，把安装包和对应的 `update-stable.json` 或 `update-beta.json` 放入同一条 `v<版本>` GitHub Release，测试版标为 pre-release。GitCode 镜像可以通过打包脚本的 `-GitCodeDownloadUrl` 生成对应镜像清单，保持两处安装包的内容与哈希一致。应用内自动检查目前使用 GitHub 主通道。Windows 工作流只构建和生成 CI 产物，公开发布需另行授权。

## 当前范围

支持 Windows 本地项目、文本会话、图片附件以及 UTF-8 / UTF-16 文本与源代码附件。ACP 文件操作、命令、审批和任务提问由官方 CLI 管理，客户端负责显示内容和提交用户选择。状态使用 Windows 无障碍实时区域，读屏软件的实际播报可通过键盘实测。
